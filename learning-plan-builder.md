### 1️⃣ Demo A: Maya Thompson — "The Test Taker"

• Student Type: New student who completed a Placement Test.
• Package: Full-Year (79 classes).
• The Challenge: How do we avoid teaching a new student things she
already knows, while giving her extra help where she is weak?
• What the Engine Does: 1. High Score (≥75%): Reduces classes on that topic by ~30% (saving
time so she isn't bored). 2. Low Score (<40%): Keeps the full class count, but shifts 15% of
the activities toward extra practice & support. 3. Average Score (40% - 74%): Keeps the standard recommended class
count.
• Key Takeaway to Explain:
│ "Diagnostic test scores automatically shape the initial plan — fast-
│ tracking strong topics and boosting practice on weak topics."

### 2️⃣ Demo B: Ethan Carter — "The Capacity Puzzle"

• Student Type: New student with no test and a short package.
• Package: Half-Year (40 classes).
• The Challenge: The full Grade 5 curriculum requires ~50+ classes, but
the parent only purchased 40 classes.
• What the Engine Does: 1. Compresses Classes: Squeezes topics down from ideal classes to
their minimum required classes (e.g., 6 classes → 4 classes). 2. Auto-Drops Non-Essentials: If it's still over 40 classes, it
automatically drops Low priority topics first, then Medium priority
topics (starting from the end of the school year). 3. Locks High Priority: High-priority core topics are NEVER auto-
dropped.
• Key Takeaway to Explain:
│ "Smart budget fitting — when class count is limited, the system
│ compresses topics and trims non-essentials to fit the purchased package,
│ while protecting high-priority core math."

### 3️⃣ Demo C: Aarav Shah — "The Mid-Course Tune-Up"

• Student Type: Returning student mid-way through his learning journey.
• Package: 24 classes remaining (Plan Update).
• The Challenge: He finished past topics faster than expected. How do we
reuse that saved time and fix current learning bottlenecks?
• What the Engine Does: 1. Recycles Saved Time: If he finished 5 planned classes in 4 classes,
1 saved class is returned to his pool for future topics. 2. Mentor View Diagnosis: Breaks down his current active topic into
individual learning objectives (shows Mastered, Stuck, or Not
Attempted). 3. Safety Warning: If capacity is still 1 class over budget even
after compression, the system shows a red warning requiring a manual
teacher decision (it won't drop High-priority topics silently).
• Key Takeaway to Explain:
│ "Live progress updates — recycles saved class hours and pinpoints exact
│ question-level gaps for the mentor to fix."

### 4️⃣ Demo D: Sofia Martinez — "The Jump-Ahead Request"

• Student Type: Parent requested to start with a specific topic (e.g.,
Fraction Arithmetic).
• Package: Full-Year (79 classes).
• The Challenge: A parent wants Fractions immediately, but Fractions
requires foundational skills in Number Sense and Multiplication.
• What the Engine Does: 1. Finds Prerequisites: Traces all required prerequisite topics
(Number Sense, Multi-Digit Operations, Factors & Primes). 2. Inserts Refreshers: Schedules short Prerequisite Refreshers (at
~50% duration) before the requested topic. 3. Teaches Target Topic: Teaches Fraction Arithmetic in full,
followed by the rest of the grade curriculum.
• Key Takeaway to Explain:
│ "Safe fast-tracking — honors parent requests while inserting short
│ refresher foundation classes so the student doesn't fail."
