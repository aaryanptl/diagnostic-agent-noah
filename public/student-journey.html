How the next test is chosen

Eight rules, checked in order. First match wins.

R0Every objective certifiedTopic closed
R1Topic under 60Re-teach the topic
R23 failed checks, or 4 rounds stalledHand to teacher

Safety first, then certify, then teach, then test. Move any of those and the loop breaks.

Certification check

5 questions on one objective, all unseen. The only thing that can finish an objective, and a pass is permanent.

One easy question wrong fails it. Three failures stops the loop and calls a human.

Outside the loop

Grade tests and multi-topic tests pick which topic to teach. This loop measures mastery inside one topic.

Placement seeds the topic score, but reports at topic level — so it writes no objective scores.
